# Security Policy

## Reporting

Report suspected vulnerabilities privately through GitHub's **Security** tab
and private vulnerability-reporting flow for this repository. If that flow is
not available, contact the repository maintainers privately and request a
secure reporting channel before sending details.

Never include credentials, launch tokens, swimmer or instructor records,
medical notes, exports, databases, logs, screenshots, internal paths, or other
operational data in a public issue.

## Supported versions

During pre-1.0 development, only the latest release and the current default
development branch receive security fixes. This policy will be revised when a
stable public release line exists.

## Scope

Reports about the separately maintained Jackrabbit Exporter belong in its own
repository. Reports about Jackrabbit Class itself must be directed to its
vendor; do not test third-party systems without authorization.
